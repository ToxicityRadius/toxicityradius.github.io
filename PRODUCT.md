# Dexter’s Town

Product requirements and confirmed user decisions live in [docs/planning/PRD.md](docs/planning/PRD.md). This is a public web portfolio for employers and freelance clients, authored with vanilla HTML/CSS/JavaScript and GSAP. The user selected a cozy pixel-art town, three featured case studies, a secondary project archive, day/night modes, and Cloudflare Pages hosting. No visitor accounts or application database.
