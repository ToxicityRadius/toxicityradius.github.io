# Dexter’s Town

## Direction
Cozy imaginative pixel-art town, approved by the user. The homepage is an Experience surface; case studies are Read surfaces. Impeccable owns cohesion, Taste supplies composition and scene choreography, Emil supplies responsive interaction detail. The user’s pixel-town direction overrides generic skill templates.

## Foundations
- Day: paper #f8f5ec, ink #233e36, muted text #52665b, surface #eaf0e2, warm contact surface #ead9bd.
- Night: paper #142922, ink #f3ead5, muted #bdc9b6, surface #203b30, warm contact #3d4938.
- Headings: self-hosted Fraunces 500, balanced, tracking -0.035em. Body: self-hosted Outfit 400. Pixel art belongs to the environment, not body copy.
- Main content width 1280px including padding. Desktop spacing 110px vertical / 64px horizontal; mobile 65px / 22px. Controls at least 44px except secondary inline links.
- Original generated raster town art: campus left, workshop center, library right. Day/night geometry matched. All labels are semantic HTML links. Town landmarks use cream signs; no text baked into artwork.

## Behavior
Desktop scene parallax and project-art drift use GSAP. Content is visible before animation initializes. Reduced motion removes all movement. Hover feedback is gated to fine pointers. Buttons react in 140ms; theme imagery fades in 250ms. Keyboard navigation is never delayed.
Mobile shows a cropped town scene with a vertical list of labeled landmark links beneath it. Case studies use ordinary page navigation, direct URLs and return links. Archive filters expose pressed states and announce the result count.
