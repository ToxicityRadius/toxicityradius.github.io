# Dexter’s Town

## Direction
Quiet countryside pixel-art town with greenery, warm stone, and restrained detail, approved by the user on 2026-10-19 after the assembled static review. The user subsequently requested a full James Chugh-inspired experience while keeping pixel art. The homepage connects entrance, personal journey, project evidence, about, services, and contact; case studies remain Read surfaces. Impeccable owns cohesion, Taste supplies composition and scene choreography, Emil supplies responsive interaction detail. The user’s pixel-town direction overrides generic skill templates.

## Foundations
- Day: paper #f8f5ec, ink #233e36, muted text #52665b, surface #eaf0e2, warm contact surface #ead9bd.
- Night: paper #142922, ink #f3ead5, muted #bdc9b6, surface #203b30, warm contact #3d4938.
- Headings: self-hosted Fraunces 500, balanced, tracking -0.035em. Body: self-hosted Outfit 400. Pixel art belongs to the environment, not body copy.
- Main content width 1280px including padding. Desktop spacing 110px vertical / 64px horizontal; mobile 65px / 22px. Controls at least 44px except secondary inline links.
- Independent generated raster layers: architecture-free terrain, distant hills, three transparent buildings (campus left, workshop center, library right), and transparent foreground, composed on one 1672 x 941 coordinate system with an SVG sky and clouds. The approved master remains an art checkpoint, not the rendered scene. Assets use lossless WebP with visible-pixel equivalence checked against generated PNGs. Night reuses the same geometry. Essential labels remain semantic HTML links.

## Behavior
The signature experience is a desktop scroll-pinned fly-in through the independently layered town, followed by a journey path that draws as the five factual chapters progress, and a selectable project box that brings one real project and its evidence forward. Earlier ambient loops and shallow parallax alone did not satisfy this intent. Direct chapter links and project buttons provide deliberate phone interaction; reduced motion uses direct state changes and ordinary reading flow. All chapters and project articles are present before scripts enhance them.

The desktop town adds scroll depth across sky, hills, terrain, buildings, and foreground, alongside coordinated water, smoke, traveler, and night-light layers. One pause/resume control stops ambient movement and freezes scroll depth; reduced motion shows a complete still scene. Playback is also suspended while the town is offscreen or the document is hidden. Motion must never gate content or navigation. Hover feedback is gated to fine pointers. Buttons react in 140ms; theme changes use a short opacity transition. Keyboard navigation is never delayed.
Mobile shows the complete town at its natural aspect ratio with large labeled landmark links beneath it; smoke and the traveler are omitted on phones. Case studies use ordinary page navigation, direct URLs and return links. Archive filters expose pressed states and announce the result count.
